```
├─────────────────────────────────────────────────────────────────────────────┤

│   │  人工调优   │                    │  自动优化   │                       │
│   └─────────────┘                    └─────────────┘                       │
│                                                                             │
│   ┌─────────────┐                    ┌─────────────┐                       │

│   │  启发式规则 │                    │  数据驱动   │                       │

│   │  事后诊断   │                    │  预防性维护 │                       │
│   └─────────────┘                    └─────────────┘                       │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 1.2 设计原则

| 原则 | 描述 | 约束 |
|-----|------|------|
| **低侵入性** | 最小化对现有代码的修改 | 通过 hook 机制集成 |
| **低延迟** | AI 推理不能成为性能瓶颈 | 推理延迟 < 1ms |
| **高可靠** | AI 决策失败不影响核心功能 | 完整的 fallback 机制 |
| **可观测** | 所有 AI 决策可追溯审计 | 完整的日志和指标 |
| **渐进式** | 支持逐步启用 AI 功能 | 配置开关控制 |

### 1.3 目标场景

```
优先级排序 (基于 ROI)

P0 - 高收益、可验证
├── Buffer Pool 智能管理
├── 查询优化器增强
└── 自适应参数调优

P1 - 中等收益
├── 智能索引管理
├── 事务调度优化
└── IO 调度优化

P2 - 探索性
├── 智能 Compaction
├── 预测性故障检测
└── 自动 Schema 优化
```

#### 2.6.1 Learned Cache Replacement (Buffer Pool LRU 污染)

```
┌─────────────────────────────────────────────────────────────────────────────┐
│           AI 解决方案 #1: Learned Cache Replacement                          │
│           目标: 智能选择驱逐页面，避免热点数据被扫描污染                      │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  ═══════════════════════════════════════════════════════════════════════   │
│  【特征提取】从 buf_page_t 结构提取                                          │
│  ═══════════════════════════════════════════════════════════════════════   │
│                                                                             │
│  ┌──────────────────────────────────────────────────────────────────────┐  │
│  │ 特征名称              │ 提取方式                    │ 数据类型      │  │
│  ├──────────────────────────────────────────────────────────────────────┤  │
│  │ access_count          │ 页面访问计数器              │ uint64        │  │
│  │ time_since_last_access│ now - page->access_time     │ uint64 (ms)   │  │
│  │ time_since_first_load │ now - page->load_time       │ uint64 (ms)   │  │
│  │ access_frequency      │ access_count / age          │ float         │  │
│  │ page_type             │ fil_page_get_type(page)     │ enum (0-7)    │  │
│  │ is_dirty              │ buf_page_is_dirty(page)     │ bool          │  │
│  │ is_old                │ page->old                   │ bool          │  │
│  │ is_from_scan          │ 追踪: 是否来自全表扫描      │ bool          │  │
│  │ buf_fix_count         │ 当前引用计数                │ uint32        │  │
│  │ lru_position          │ 在 LRU 链表中的位置         │ uint32        │  │
│  │ table_id              │ 所属表 ID (用于 embedding)  │ uint64        │  │
│  │ index_id              │ 所属索引 ID                 │ uint64        │  │
│  │ bp_usage_ratio        │ Buffer Pool 整体使用率      │ float         │  │
│  │ dirty_page_ratio      │ 脏页占比                    │ float         │  │
│  │ current_qps           │ 当前系统 QPS                │ float         │  │
│  └──────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
│  // 代码示例                                                                │
│  struct PageFeatures extract_page_features(buf_page_t* page) {              │
│      PageFeatures f;                                                        │
│      uint64_t now = ut_time_monotonic_ms();                                 │
│                                                                             │
│      f.access_count = page_stats[page->id].access_count;                    │
│      f.time_since_last_access = now - page->access_time;                    │
│      f.time_since_first_load = now - page->load_time;                       │
│      f.access_frequency = f.access_count * 1000.0 / f.time_since_first_load;│
│      f.page_type = fil_page_get_type(page->frame);                          │
│      f.is_dirty = buf_page_is_dirty(page);                                  │
│      f.is_old = page->old;                                                  │
│      f.is_from_scan = page_stats[page->id].from_scan;                       │
│      f.buf_fix_count = page->buf_fix_count;                                 │
│      f.lru_position = get_lru_position(page);                               │
│      f.bp_usage_ratio = buf_pool->stat.n_pages_used / buf_pool->size;       │
│      f.dirty_page_ratio = buf_pool->stat.n_dirty / buf_pool->stat.n_pages;  │
│      f.current_qps = srv_stats.n_queries.rate();                            │
│                                                                             │
│      return f;                                                              │
│  }                                                                          │
│                                                                             │
│  ═══════════════════════════════════════════════════════════════════════   │
│  【归一化】将原始值转换为 [0,1] 范围                                         │
│  ═══════════════════════════════════════════════════════════════════════   │
│                                                                             │
│  ┌──────────────────────────────────────────────────────────────────────┐  │
│  │ 特征名称              │ 归一化方法               │ 公式/说明        │  │
│  ├──────────────────────────────────────────────────────────────────────┤  │
│  │ access_count          │ Log 归一化               │ log(1+x) / 15    │  │
│  │ time_since_last_access│ Min-Max (上限100秒)      │ min(x,100000)/100000│ │
│  │ time_since_first_load │ Min-Max (上限1小时)      │ min(x,3600000)/3600000││
│  │ access_frequency      │ Log 归一化               │ log(1+x) / 10    │  │
│  │ page_type             │ One-Hot 编码             │ [0,0,1,0,0,0,0,0]│  │
│  │ is_dirty              │ 直接使用                 │ 0 或 1           │  │
│  │ is_old                │ 直接使用                 │ 0 或 1           │  │
│  │ is_from_scan          │ 直接使用                 │ 0 或 1           │  │
│  │ buf_fix_count         │ Min-Max (上限10)         │ min(x,10) / 10   │  │
│  │ lru_position          │ 除以链表长度             │ x / lru_len      │  │
│  │ bp_usage_ratio        │ 已是比例                 │ 直接使用         │  │
│  │ dirty_page_ratio      │ 已是比例                 │ 直接使用         │  │
│  │ current_qps           │ Log 归一化               │ log(1+x) / 15    │  │
│  └──────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
│  // 归一化代码                                                              │
│  std::vector<float> normalize(const PageFeatures& f) {                      │
│      std::vector<float> v;                                                  │
│      v.push_back(std::log1p(f.access_count) / 15.0);                        │
│      v.push_back(std::min(f.time_since_last_access, 100000UL) / 100000.0);  │
│      v.push_back(std::min(f.time_since_first_load, 3600000UL) / 3600000.0); │
│      v.push_back(std::log1p(f.access_frequency) / 10.0);                    │
│      // One-Hot for page_type (8 types)                                     │
│      for (int i = 0; i < 8; i++) v.push_back(f.page_type == i ? 1.0 : 0.0); │
│      v.push_back(f.is_dirty ? 1.0 : 0.0);                                   │
│      v.push_back(f.is_old ? 1.0 : 0.0);                                     │
│      v.push_back(f.is_from_scan ? 1.0 : 0.0);                               │
│      v.push_back(std::min(f.buf_fix_count, 10U) / 10.0);                    │
│      v.push_back(f.lru_position);                                           │
│      v.push_back(f.bp_usage_ratio);                                         │
│      v.push_back(f.dirty_page_ratio);                                       │
│      v.push_back(std::log1p(f.current_qps) / 15.0);                         │
│      return v;  // 总共 20 维                                               │
│  }                                                                          │
│                                                                             │
│  ═══════════════════════════════════════════════════════════════════════   │
│  【推理】神经网络模型                                                        │
│  ═══════════════════════════════════════════════════════════════════════   │
│                                                                             │
│  模型结构: MLP (20 → 64 → 32 → 1)                                           │
│                                                                             │
│  输入: 20维特征向量                                                         │
│  输出: 1个值 (0-1)，表示"应该被驱逐的概率"                                  │
│                                                                             │
│  // 推理代码                                                                │
│  float predict_eviction_score(const std::vector<float>& features) {         │
│      Ort::Value input = create_tensor(features);                            │
│      auto output = session_.Run({}, {"input"}, {input}, {"output"});        │
│      return output[0].GetTensorData<float>()[0];  // 返回 0-1 分数          │
│  }                                                                          │
│                                                                             │
│  ═══════════════════════════════════════════════════════════════════════   │
│  【Action】执行驱逐                                                          │
│  ═══════════════════════════════════════════════════════════════════════   │
│                                                                             │
│  Action 类型: 选择要驱逐的页面                                              │
│                                                                             │
│  // 决策逻辑                                                                │
│  buf_page_t* select_victim(buf_pool_t* pool) {                              │
│      auto candidates = get_eviction_candidates(pool, 16);  // 取16个候选    │
│                                                                             │
│      float max_score = -1;                                                  │
│      buf_page_t* victim = nullptr;                                          │
│                                                                             │
│      for (auto* page : candidates) {                                        │
│          auto features = normalize(extract_page_features(page));            │

│                                                                             │
│          if (score > max_score) {                                           │
│              max_score = score;                                             │
│              victim = page;                                                 │
│          }                                                                  │
│      }                                                                      │
│                                                                             │
│      // 记录决策用于后续反馈                                                │
│      record_eviction_decision(victim, max_score);                           │
│      return victim;                                                         │
│  }                                                                          │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

```cpp
class LearnedBufferPoolAgent : public IKernelAgent {
public:
    /**
     * 选择要驱逐的页面
     * 在 buf_LRU_get_free_block() 中调用
     */
    buf_page_t* select_victim() {
        if (!is_enabled()) {
            return fallback_lru_victim();  // 回退到 LRU
        }
        
        // 1. 收集候选页面特征
        std::vector<BufferPoolFeatures> candidates;
        for (auto* page : get_eviction_candidates()) {
            candidates.push_back(extract_features(page));
        }
        
        // 2. 批量推理获取驱逐分数
        auto scores = inference_engine_->batch_infer(
            encode_features(candidates));
        
        // 3. 选择分数最高的页面驱逐
        size_t victim_idx = argmax(scores);
        
        // 4. 记录决策用于后续学习
        record_decision(candidates[victim_idx], scores[victim_idx]);
        
        return candidates[victim_idx].page;
    }
    
    /**
     * 预读取预测
     * 在 buf_read_page() 后调用
     */
    std::vector<page_id_t> predict_prefetch(page_id_t current_page) {
        if (!is_enabled()) {
            return fallback_linear_prefetch(current_page);
        }
        
        // 基于访问模式预测下一个可能访问的页面
        auto features = extract_access_pattern_features(current_page);
        auto predictions = prefetch_model_->predict(features);
        
        return filter_already_cached(predictions);
    }
    
private:
    std::unique_ptr<IInferenceEngine> inference_engine_;
    std::unique_ptr<PrefetchModel> prefetch_model_;
};
```

### 4.2 Learned Query Optimizer

#### 4.2.1 基数估计器 (Learned Cardinality Estimator)

```cpp
/**
 * 学习的基数估计器 - 替代传统直方图
 */
class LearnedCardinalityEstimator {
public:
    /**
     * 估计查询的基数
     * 在 optimizer 的 estimate_rowcount() 中调用
     */
    double estimate(const Query& query) {
        if (!is_enabled()) {
            return fallback_histogram_estimate(query);
        }
        
        // 1. 提取查询特征
        QueryFeatures features = extract_query_features(query);
        
        // 2. 编码特征
        auto encoded = query_encoder_->encode(features);
        
        // 3. 模型推理
        double log_cardinality = model_->infer(encoded)[0];
        
        // 4. 返回基数估计
        return std::exp(log_cardinality);
    }
    
private:
    /**
     * 查询特征提取
     */
    QueryFeatures extract_query_features(const Query& query) {
        QueryFeatures f;
        
        // 表级特征
        for (const auto& table : query.tables) {
            f.table_sizes.push_back(get_table_size(table));
            f.table_embeddings.push_back(get_table_embedding(table));
        }
        
        // 谓词特征
        for (const auto& pred : query.predicates) {
            f.predicate_types.push_back(pred.type);  // =, <, >, LIKE, IN
            f.column_embeddings.push_back(get_column_embedding(pred.column));
            f.literal_embeddings.push_back(encode_literal(pred.value));
        }
        
        // Join 特征
        for (const auto& join : query.joins) {
            f.join_types.push_back(join.type);
            f.join_column_pairs.push_back({
                get_column_embedding(join.left),
                get_column_embedding(join.right)
            });
        }
        
        return f;
    }
};
```

```cpp
class DeadlockPredictionAgent : public IKernelAgent {
public:
    /**
     * 预测当前锁请求是否会导致死锁
     * 在 lock_rec_lock() 之前调用
     */
    DeadlockRisk predict_deadlock(
        const trx_t* trx,
        const lock_t* requested_lock
    ) {
        // 1. 构建当前锁等待图特征
        auto graph_features = build_wait_graph_features();
        
        // 2. 添加当前事务和请求的锁
        auto trx_features = extract_trx_features(trx);
        auto lock_features = extract_lock_features(requested_lock);
        
        // 3. 图神经网络预测
        auto combined = concat(graph_features, trx_features, lock_features);
        float risk_score = deadlock_model_->predict(combined);
        
        return DeadlockRisk{
            .score = risk_score,
            .should_wait = risk_score < deadlock_threshold_,
            .suggested_action = risk_score >= deadlock_threshold_ 
                ? Action::ABORT_AND_RETRY 
                : Action::WAIT
        };
    }
    
private:
    /**
     * 构建锁等待图特征
     */
    GraphFeatures build_wait_graph_features() {
        GraphFeatures gf;
        
        // 遍历所有等待关系
        for (const auto& [waiting_trx, holding_trx] : get_wait_edges()) {
            gf.add_edge(
                waiting_trx->id,
                holding_trx->id,
                extract_edge_features(waiting_trx, holding_trx)
            );
        }
        
        // 节点特征
        for (const auto* trx : get_active_transactions()) {
            gf.add_node(trx->id, extract_trx_features(trx));
        }
        
        return gf;
    }
};
```

```cpp
            OrtArenaAllocator, OrtMemTypeDefault);

            const_cast<float*>(features.data()),
            features.size(),
            input_shape.data(),
            input_shape.size()
        );

        auto output_tensors = session_->Run(
            Ort::RunOptions{nullptr},
            input_names_.data(),

        size_t output_size = output_tensors[0].GetTensorTypeAndShapeInfo()

        update_stats(end - start);
        
        return std::vector<float>(output_data, output_data + output_size);
    }

    std::unique_ptr<Ort::Session> session_;
```

```cpp
/**
 * 轻量级 MLP 推理 - 纯 C++ 实现，无外部依赖
 * 适用于简单模型，延迟要求极高的场景
 */
class LightweightMLP {
public:
    LightweightMLP(const std::vector<int>& layer_sizes) {
        // 初始化权重和偏置
        for (size_t i = 0; i < layer_sizes.size() - 1; ++i) {
            weights_.emplace_back(layer_sizes[i], layer_sizes[i + 1]);
            biases_.emplace_back(layer_sizes[i + 1]);
        }
    }
    
    /**
     * 从文件加载权重
     */
    bool load_weights(const std::string& path) {
        std::ifstream file(path, std::ios::binary);
        if (!file) return false;
        
        for (auto& w : weights_) {
            file.read(reinterpret_cast<char*>(w.data()), 
                      w.size() * sizeof(float));
        }
        for (auto& b : biases_) {
            file.read(reinterpret_cast<char*>(b.data()), 
                      b.size() * sizeof(float));
        }
        return file.good();
    }
    
    /**
     * 前向推理 - 高度优化
     */
    std::vector<float> forward(const std::vector<float>& input) {
        std::vector<float> activation = input;
        
        for (size_t i = 0; i < weights_.size(); ++i) {
            activation = matmul_add(activation, weights_[i], biases_[i]);
            
            // 最后一层不用激活函数
            if (i < weights_.size() - 1) {
                relu_inplace(activation);
            }
        }
        
        return activation;
    }
    
private:
    // SIMD 优化的矩阵乘法
    std::vector<float> matmul_add(
        const std::vector<float>& x,
        const Matrix& W,
        const std::vector<float>& b
    ) {
        std::vector<float> result(W.cols());
        
        #pragma omp simd
        for (int j = 0; j < W.cols(); ++j) {
            float sum = b[j];
            for (int i = 0; i < W.rows(); ++i) {
                sum += x[i] * W(i, j);
            }
            result[j] = sum;
        }
        
        return result;
    }
    
    void relu_inplace(std::vector<float>& x) {
        #pragma omp simd
        for (size_t i = 0; i < x.size(); ++i) {
            x[i] = std::max(0.0f, x[i]);
        }
    }
    
    std::vector<Matrix> weights_;
    std::vector<std::vector<float>> biases_;
};
```

```cpp
     * 热更新模型 - 无需重启
     */

        model_versions_[agent_name]++;

                 agent_name.c_str(), model_versions_[agent_name]);

                hot_reload_model(name, path);

            }
```

```cpp
        ai_cardinality_estimator = new LearnedCardinalityEstimator(
            ai_model_manager->get_engine("cardinality"));
        sql_print_information("Cardinality AI Estimator initialized");
    }
    
    // 4. 启动后台线程 (模型更新、指标收集)
    ai_background_thread = std::thread(ai_background_loop);
    
    sql_print_information("AI subsystem initialized successfully");
    return true;
}

/**
 * AI 子系统关闭
 */
static void ai_shutdown() {
    if (!srv_ai_enabled) return;
    
    ai_shutdown_flag = true;
    ai_background_thread.join();
    
    delete ai_buffer_pool_agent;
    delete ai_cardinality_estimator;
    delete ai_model_manager;
    delete ai_inference_engine;
}
```

```
│      // Log 归一化: 处理访问次数等分布不均的特征                            │

│                                                                             │

│      normalized.push_back(f.access_frequency / 1000.0);     // 最大1000次/秒│
│                                                                             │

│      normalized.push_back(f.is_dirty);                                      │
│      normalized.push_back(f.is_old);                                        │
│      normalized.push_back(f.is_from_scan);                                  │
│      normalized.push_back(f.bp_usage_ratio);                                │
│      normalized.push_back(f.dirty_page_ratio);                              │

│      // 类别特征 One-Hot 编码                                               │
│      for (int i = 0; i < 5; i++) {                                          │
│          normalized.push_back(f.page_type == i ? 1.0 : 0.0);                │
│      }                                                                      │
│                                                                             │
│      return normalized;  // 返回 15 维特征向量                              │
│  }                                                                          │
```

### C.1 神经网络推理基础

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    神经网络推理 - 直观解释                                   │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  推理 = 用训练好的模型计算输出                                               │
│                                                                             │
│  类比: 一个函数 f(x)，训练过程确定了函数的参数，推理就是计算 f(x) 的值       │
│                                                                             │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │                    单层神经网络 (最简单情况)                         │   │
│  │                                                                      │   │
│  │   输入特征 x              权重 W              偏置 b                 │   │
│  │   ┌───┐                  ┌─────────┐         ┌───┐                  │   │
│  │   │x₁ │=0.5              │w₁₁ w₁₂ │         │b₁ │=0.1               │   │
│  │   │x₂ │=0.3      ×       │w₂₁ w₂₂ │    +    │b₂ │=0.2               │   │
│  │   │x₃ │=0.8              │w₃₁ w₃₂ │         └───┘                   │   │
│  │   └───┘                  └─────────┘                                 │   │
│  │                                                                      │   │
│  │   计算: output = activation(x · W + b)                               │   │
│  │                                                                      │   │
│  │   具体:                                                              │   │
│  │   y₁ = relu(0.5×w₁₁ + 0.3×w₂₁ + 0.8×w₃₁ + 0.1)                     │   │
│  │   y₂ = relu(0.5×w₁₂ + 0.3×w₂₂ + 0.8×w₃₂ + 0.2)                     │   │
│  │                                                                      │   │
│  │   其中 relu(x) = max(0, x)                                          │   │
│  │                                                                      │   │
│  └──────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │                    多层神经网络 (MLP)                                │   │
│  │                                                                      │   │
│  │   输入层         隐藏层1        隐藏层2        输出层                │   │
│  │   (15个特征)     (64神经元)     (32神经元)     (1个输出)             │   │
│  │                                                                      │   │
│  │      ●─────────●                                                    │   │
│  │      ●─────────●────────●                                           │   │
│  │      ●─────────●────────●────────●                                  │   │
│  │      ●─────────●────────●────────●────────● → 驱逐分数              │   │
│  │      ●─────────●────────●────────●                                  │   │
│  │      ...       ...      ...                                          │   │
│  │      ●─────────●────────●                                           │   │
│  │                                                                      │   │
│  │   每层计算: output = relu(input × W + b)                            │   │
│  │   最后一层: output = sigmoid(input × W + b)  // 输出0-1             │   │
│  │                                                                      │   │
│  └──────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

```
│      }                                                                      │

│  ═══════════════════════════════════════════════════════════════════════   │
│                                                                             │
│  模型学习到的规律:                                                          │
│  1. is_from_scan = 1 的页面通常是"一次性"访问，很少再被访问                │

│  传统 LRU 可能会错误地驱逐 Page A (如果它刚好在链表尾部)                    │
```

```
│  │   │               victim = candidates[argmax(scores)]          │     │   │
│  │   │                                                            │     │   │
│  │   │               统计: ai_evictions++                         │     │   │
│  │   │                                                            │     │   │
│  │   └────────────────────────────────────────────────────────────┘     │   │
│  │                               │                                      │   │

│  │   │               victim = LRU_tail_page                        │   │   │
│  │   │                                                              │   │   │
│  │   │               统计: lru_fallbacks++                         │   │   │
│  │   │               日志: "AI fallback: reason=xxx"               │   │   │
│  │   │                                                              │   │   │
│  │   └─────────────────────────────────────────────────────────────┘   │   │
│  │                                                                      │   │
│  └──────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│  // 代码实现                                                                │
│  buf_page_t* select_victim_with_fallback(buf_pool_t* buf_pool) {           │
│      // 检查 AI 是否启用                                                    │
│      if (!srv_ai_buffer_pool_enabled || ai_agent == nullptr) {              │
│          ai_stats.lru_fallbacks++;                                          │
│          return fallback_lru_select(buf_pool);  // 传统 LRU                │
│      }                                                                      │
│                                                                             │
│      // 尝试 AI 推理 (带超时)                                               │
│      auto start = std::chrono::high_resolution_clock::now();                │
│      try {                                                                  │
│          auto victim = ai_agent->select_victim(buf_pool);                   │
│                                                                             │
│          auto elapsed = std::chrono::high_resolution_clock::now() - start; │
│          if (elapsed > std::chrono::microseconds(srv_ai_inference_timeout)) {│
│              // 超时，记录并 fallback                                       │
│              ai_stats.inference_timeouts++;                                 │
│              ai_stats.lru_fallbacks++;                                      │
│              return fallback_lru_select(buf_pool);                          │
│          }                                                                  │
│                                                                             │
│          if (victim != nullptr) {                                           │
│              ai_stats.ai_evictions++;                                       │
│              return victim;                                                 │
│          }                                                                  │
│      } catch (const std::exception& e) {                                    │
│          // 推理异常，fallback                                              │
│          sql_print_warning("AI inference failed: %s", e.what());            │
│          ai_stats.lru_fallbacks++;                                          │
│      }                                                                      │
│                                                                             │
│      return fallback_lru_select(buf_pool);                                  │
│  }                                                                          │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### E.2 不同模型的训练方法

#### E.2.1 Buffer Pool 缓存替换模型训练

```
┌─────────────────────────────────────────────────────────────────────────────┐
│         Buffer Pool 缓存替换模型: 监督学习 (Supervised Learning)            │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  【训练目标】                                                                │
│  预测页面的"应该被驱逐的程度" = 1 - P(短期内再次访问)                       │
│                                                                             │
│  【标签生成】使用 Belady's Algorithm (最优离线算法) 作为教师                │
│                                                                             │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │           Belady's Algorithm (最优缓存替换)                          │   │
│  │                                                                      │   │
│  │   给定完整的未来访问序列，Belady 选择"最晚再次访问"的页面驱逐        │   │
│  │                                                                      │   │
│  │   示例: Buffer 容量=3, 当前页面: [A, B, C]                          │   │
│  │         未来访问: D, A, E, B, D, A, C, ...                          │   │
│  │                                                                      │   │
│  │   计算下次访问距离:                                                  │   │
│  │     A: 下次访问在位置 2 (距离=2)                                    │   │
│  │     B: 下次访问在位置 4 (距离=4)                                    │   │
│  │     C: 下次访问在位置 7 (距离=7) ← 最远，应该被驱逐                 │   │
│  │                                                                      │   │
│  │   标签: label(A)=0.2, label(B)=0.5, label(C)=1.0 (归一化距离)       │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│  【训练流程】                                                                │
│                                                                             │
│  ┌──────────────────────────────────────────────────────────────────────┐  │
│  │                                                                       │  │
│  │   1. 运行 Workload 并收集完整访问序列                                 │  │
│  │      access_sequence = [page_1, page_2, page_3, ..., page_N]         │  │
│  │                                                                       │  │
│  │   2. 对序列中每个时间点，计算 Belady 标签                             │  │
│  │      for t in range(N):                                               │  │
│  │          for page in buffer_at_time_t:                                │  │
│  │              next_access = find_next_access(page, t)                  │  │
│  │              label = normalize_distance(next_access - t)              │  │
│  │                                                                       │  │
│  │   3. 提取特征并构建训练集                                             │  │
│  │      training_data = [(features(page, t), label) for all pages, t]   │  │
│  │                                                                       │  │
│  │   4. 训练神经网络                                                     │  │
│  │      model = MLP(input_dim=20, hidden=[64, 32], output_dim=1)        │  │
│  │      loss_fn = MSELoss()  # 回归任务                                  │  │
│  │      optimizer = Adam(lr=0.001)                                       │  │
│  │                                                                       │  │
│  │      for epoch in range(100):                                         │  │
│  │          for batch in dataloader:                                     │  │
│  │              pred = model(batch.features)                             │  │
│  │              loss = loss_fn(pred, batch.labels)                       │  │
│  │              loss.backward()                                          │  │
│  │              optimizer.step()                                         │  │
│  │                                                                       │  │
│  │   5. 导出为 ONNX 格式                                                 │  │
│  │      torch.onnx.export(model, sample_input, "eviction.onnx")         │  │
│  │                                                                       │  │
│  └──────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
│  【损失函数】                                                                │
│  L = MSE(predicted_score, belady_label) + λ * L2_regularization            │
│                                                                             │
│  【超参数】                                                                  │
│  - Learning rate: 0.001 (Adam optimizer)                                    │
│  - Batch size: 1024                                                         │
│  - Hidden layers: [64, 32]                                                  │
│  - Epochs: 50-100 (早停)                                                    │
│  - Regularization: L2 weight decay = 0.0001                                 │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

```
│  预测 log10(实际结果行数)                                                   │
│  使用 log 是因为基数范围很大 (1 ~ 10亿)                                     │
│                                                                             │
│  【标签生成】直接执行查询获取真实基数                                        │
│                                                                             │
│  // 训练数据收集                                                            │
│  for query in query_set:                                                    │
│      features = extract_query_features(query)                               │
│                                                                             │
│      # 实际执行获取真实基数                                                 │
│      result = execute(query)                                                │
│      actual_cardinality = result.row_count                                  │
│                                                                             │
│      # 或者使用 EXPLAIN ANALYZE                                             │
│      explain = execute(f"EXPLAIN ANALYZE {query}")                          │
│      actual_cardinality = parse_actual_rows(explain)                        │
│                                                                             │
│      training_data.append({                                                 │
│          'features': features,                                              │
│          'label': log10(max(1, actual_cardinality))                         │
│      })                                                                     │
│                                                                             │
│  【训练流程】                                                                │
│                                                                             │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │   # 模型结构: Multi-Set Convolutional Network (MSCN)                │   │
│  │                                                                      │   │
│  │   class CardinalityModel(nn.Module):                                 │   │
│  │       def __init__(self):                                            │   │
│  │           # 表特征编码器                                              │   │
│  │           self.table_encoder = nn.Sequential(                        │   │
│  │               nn.Linear(table_feature_dim, 64),                      │   │
│  │               nn.ReLU(),                                             │   │
│  │               nn.Linear(64, 32)                                      │   │
│  │           )                                                          │   │
│  │           # 谓词特征编码器                                            │   │
│  │           self.predicate_encoder = nn.Sequential(                    │   │
│  │               nn.Linear(predicate_feature_dim, 64),                  │   │
│  │               nn.ReLU(),                                             │   │
│  │               nn.Linear(64, 32)                                      │   │
│  │           )                                                          │   │
│  │           # Join 特征编码器                                          │   │
│  │           self.join_encoder = nn.Sequential(                         │   │
│  │               nn.Linear(join_feature_dim, 64),                       │   │
│  │               nn.ReLU(),                                             │   │
│  │               nn.Linear(64, 32)                                      │   │
│  │           )                                                          │   │
│  │           # 最终预测层                                                │   │
│  │           self.output_layer = nn.Sequential(                         │   │
│  │               nn.Linear(32*3, 128),                                  │   │
│  │               nn.ReLU(),                                             │   │
│  │               nn.Linear(128, 64),                                    │   │
│  │               nn.ReLU(),                                             │   │
│  │               nn.Linear(64, 1)                                       │   │
│  │           )                                                          │   │
│  │                                                                      │   │
│  │       def forward(self, tables, predicates, joins):                  │   │
│  │           # Set aggregation (平均池化处理可变数量)                    │   │
│  │           t_emb = self.table_encoder(tables).mean(dim=0)             │   │
│  │           p_emb = self.predicate_encoder(predicates).mean(dim=0)     │   │
│  │           j_emb = self.join_encoder(joins).mean(dim=0)               │   │
│  │           combined = torch.cat([t_emb, p_emb, j_emb])                │   │
│  │           return self.output_layer(combined)                         │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│  【损失函数】Q-Error (查询估计的标准误差度量)                                │
│                                                                             │
│  Q-Error = max(predicted/actual, actual/predicted)                          │
│                                                                             │
│  // 使用 Q-Error 的对数形式作为损失                                         │
│  def q_error_loss(pred_log, actual_log):                                    │
│      pred = 10 ** pred_log                                                  │
│      actual = 10 ** actual_log                                              │
│      q_error = max(pred/actual, actual/pred)                                │
│      return log(q_error)                                                    │
│                                                                             │
│  // 或简化为: |pred_log - actual_log| (对数空间的 MAE)                      │
│  loss = |pred_log - actual_log|                                             │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

#### E.2.3 刷脏策略模型训练 (强化学习)

```
┌─────────────────────────────────────────────────────────────────────────────┐
│         自适应刷脏模型: 强化学习 (Reinforcement Learning)                    │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  【为什么用强化学习】                                                        │
│  - 没有明确的"正确答案"标签                                                 │
│  - 决策有长期影响 (刷脏太多影响当前性能，刷脏太少导致 Checkpoint 抖动)       │
│  - 需要探索不同策略                                                         │
│                                                                             │
│  【MDP 建模】                                                                │
│                                                                             │
│  ┌──────────────────────────────────────────────────────────────────────┐  │
│  │  状态 (State):                                                        │  │
│  │    s = [dirty_ratio, redo_usage, io_util, qps, avg_latency, ...]     │  │
│  │                                                                       │  │
│  │  动作 (Action):                                                       │  │
│  │    a = 本次刷脏页数 ∈ {0, 10, 50, 100, 200, 500, 1000}               │  │
│  │    (离散化动作空间)                                                   │  │
│  │                                                                       │  │
│  │  奖励 (Reward):                                                       │  │
│  │    r = -α * query_latency_increase                                   │  │
│  │        -β * checkpoint_duration                                       │  │
│  │        -γ * io_spike_penalty                                          │  │
│  │        +δ * throughput_improvement                                    │  │
│  │                                                                       │  │
│  │  目标: 最大化长期累计奖励 (最小化延迟抖动，保持稳定吞吐)              │  │
│  └──────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
│  【训练流程: PPO 算法】                                                      │
│                                                                             │
│  ┌──────────────────────────────────────────────────────────────────────┐  │
│  │                                                                       │  │
│  │   Actor-Critic 网络结构:                                              │  │
│  │                                                                       │  │
│  │   State ──→ SharedMLP(64,64) ──┬──→ Actor(32) ──→ π(a|s)             │  │
│  │                                │                                      │  │
│  │                                └──→ Critic(32) ──→ V(s)              │  │
│  │                                                                       │  │
│  │   训练循环:                                                           │  │
│  │   for iteration in range(1000):                                       │  │
│  │       # 1. 收集经验                                                   │  │
│  │       trajectories = []                                               │  │
│  │       for _ in range(batch_size):                                     │  │
│  │           s = get_current_state()                                     │  │
│  │           a = actor.sample_action(s)                                  │  │
│  │           execute_flush(a)                                            │  │
│  │           s_next = get_current_state()                                │  │
│  │           r = compute_reward(s, a, s_next)                            │  │
│  │           trajectories.append((s, a, r, s_next))                      │  │
│  │                                                                       │  │
│  │       # 2. 计算优势估计 (GAE)                                         │  │
│  │       advantages = compute_gae(trajectories)                          │  │
│  │                                                                       │  │
│  │       # 3. PPO 更新                                                   │  │
│  │       for _ in range(ppo_epochs):                                     │  │
│  │           ratio = π_new(a|s) / π_old(a|s)                             │  │
│  │           clipped_ratio = clip(ratio, 1-ε, 1+ε)                       │  │
│  │           policy_loss = -min(ratio*A, clipped_ratio*A)                │  │
│  │           value_loss = (V(s) - returns)²                              │  │
│  │           loss = policy_loss + c1*value_loss - c2*entropy             │  │
│  │           optimizer.step()                                            │  │
│  │                                                                       │  │
│  └──────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
│  【训练环境】                                                                │
│  - 使用 MySQL 模拟器加速训练 (不需要真实 IO)                                │
│  - 或在测试环境使用加速时间模拟                                             │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

```

├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
```

```
│  │                                                 │                    │   │
│  │                                                 ▼                    │   │
│  │   ┌──────────────────┐               ┌──────────────────────┐       │   │
│  │   │  Model Loader    │               │  重新训练 (GPU)       │       │   │

│                                                                             │
│  // 离线重训练伪代码                                                        │
│  def offline_retrain(feedback_data, old_model):                             │
│      # 1. 合并历史数据和新反馈                                              │
│      all_data = historical_data + feedback_data                             │
│                                                                             │
│      # 2. 从反馈构造训练样本                                                │
│      training_samples = []                                                  │
│      for fb in feedback_data:                                               │
│          sample = {                                                         │
│              'features': fb.features,                                       │
│              'label': compute_label_from_feedback(fb)                       │
│          }                                                                  │
│          training_samples.append(sample)                                    │
│                                                                             │
│      # 3. 微调或完全重训练                                                  │
│      new_model = fine_tune(old_model, training_samples, epochs=10)          │
│      # 或                                                                   │
│      new_model = train_from_scratch(all_data, epochs=50)                    │
│                                                                             │
│      # 4. 验证新模型                                                        │
│      if validate(new_model) > validate(old_model):                          │
│          export_onnx(new_model, "model_v2.onnx")                            │
│          deploy_to_mysql(new_model)                                         │
│                                                                             │
│  ╔═══════════════════════════════════════════════════════════════════════╗ │
│  ║  方案 B: 在线增量学习 (Online Incremental Learning)                     ║ │
│  ╚═══════════════════════════════════════════════════════════════════════╝ │
│                                                                             │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │                                                                      │   │
│  │   适用于: 需要快速适应的场景 (如: 负载模式突变)                       │   │
│  │                                                                      │   │
│  │   挑战:                                                              │   │
│  │   - 不能在内核中运行反向传播 (太慢，需要 GPU)                        │   │
│  │   - 需要保证稳定性 (不能因学习导致性能下降)                          │   │
│  │                                                                      │   │
│  │   解决方案: 轻量级在线学习 (仅更新最后一层/使用线性模型)              │   │
│  │                                                                      │   │
│  │   ┌────────────────────────────────────────────────────────────┐    │   │
│  │   │                                                             │    │   │
│  │   │   Neural Network (冻结)                                     │    │   │
│  │   │   ┌──────────────────────────┐                              │    │   │
│  │   │   │ Input → Hidden → Hidden │ → feature_embedding          │    │   │
│  │   │   │ (固定权重，不更新)       │   (128 维)                    │    │   │
│  │   │   └──────────────────────────┘        │                     │    │   │
│  │   │                                       ▼                     │    │   │
│  │   │                              ┌──────────────────┐           │    │   │
│  │   │                              │ Linear Layer     │           │    │   │
│  │   │                              │ (在线更新)        │           │    │   │
│  │   │                              │ W·embedding + b  │           │    │   │
│  │   │                              └────────┬─────────┘           │    │   │
│  │   │                                       │                     │    │   │
│  │   │                                       ▼                     │    │   │
│  │   │                                   prediction                │    │   │
│  │   │                                                             │    │   │
│  │   └────────────────────────────────────────────────────────────┘    │   │
│  │                                                                      │   │
│  │   // 在线更新代码 (简单的线性回归更新)                               │   │
│  │   void online_update(const Feedback& fb) {                           │   │
│  │       // 1. 获取 embedding (通过冻结的神经网络)                      │   │
│  │       auto embedding = frozen_nn_->forward(fb.features);             │   │
│  │                                                                      │   │
│  │       // 2. 计算预测误差                                             │   │
│  │       float prediction = dot(W_, embedding) + b_;                    │   │
│  │       float error = fb.actual_label - prediction;                    │   │
│  │                                                                      │   │
│  │       // 3. 梯度下降更新线性层                                       │   │
│  │       float learning_rate = 0.001;                                   │   │
│  │       for (int i = 0; i < embedding.size(); i++) {                   │   │
│  │           W_[i] += learning_rate * error * embedding[i];             │   │
│  │       }                                                              │   │
│  │       b_ += learning_rate * error;                                   │   │
│  │   }                                                                  │   │
│  │                                                                      │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│  ╔═══════════════════════════════════════════════════════════════════════╗ │
│  ║  方案 C: A/B 测试 + 淘汰机制                                            ║ │
│  ╚═══════════════════════════════════════════════════════════════════════╝ │
│                                                                             │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │                                                                      │   │
│  │   同时运行多个模型版本，基于实际效果自动切换:                         │   │
│  │                                                                      │   │
│  │   ┌───────────┐  ┌───────────┐  ┌───────────┐                       │   │
│  │   │ Model v1  │  │ Model v2  │  │ Model v3  │                       │   │
│  │   │ (当前)    │  │ (候选)    │  │ (新训练)  │                       │   │
│  │   └─────┬─────┘  └─────┬─────┘  └─────┬─────┘                       │   │
│  │         │              │              │                              │   │
│  │         ▼              ▼              ▼                              │   │
│  │   ┌─────────────────────────────────────────────────────────────┐   │   │
│  │   │                  Multi-Armed Bandit                         │   │   │
│  │   │                                                              │   │   │
│  │   │  UCB 算法: 选择 argmax(reward_avg + sqrt(2*ln(n)/n_i))      │   │   │
│  │   │                                                              │   │   │
│  │   │  - 大部分请求用当前最佳模型                                  │   │   │
│  │   │  - 小部分请求探索其他模型                                    │   │   │
│  │   │  - 统计各模型实际效果                                        │   │   │
│  │   │  - 效果好的模型逐渐获得更多流量                              │   │   │
│  │   └─────────────────────────────────────────────────────────────┘   │   │
│  │                                                                      │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### G.4 解决方案: 混合架构 (AI + 规则)

```
┌─────────────────────────────────────────────────────────────────────────────┐
│              解决方案 #3: AI 增强而非 AI 替换                                │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  【核心思想】                                                                │
│  AI 作为传统算法的补充，而非完全替换。即使 AI 失效，系统仍能正常工作。        │
│                                                                             │
│  ┌──────────────────────────────────────────────────────────────────────┐  │
│  │                                                                       │  │
│  │   传统方法 (永远可用)              AI 增强 (可选)                     │  │
│  │   ────────────────────            ───────────────                    │  │
│  │                                                                       │  │
│  │   Buffer Pool:                                                        │  │
│  │   ┌──────────────────────────────────────────────────────────────┐   │  │
│  │   │  LRU (基础) ─────────────────────────────────────────────────│   │  │
│  │   │       ↑                                                       │   │  │
│  │   │       │ AI 调整                                               │   │  │
│  │   │       │ 在 LRU 候选中重新排序                                 │   │  │
│  │   │       │                                                       │   │  │
│  │   │  ┌────┴─────┐                                                │   │  │
│  │   │  │ AI Model │ (可禁用)                                       │   │  │
│  │   │  └──────────┘                                                │   │  │
│  │   └──────────────────────────────────────────────────────────────┘   │  │
│  │                                                                       │  │
│  │   基数估计:                                                           │  │
│  │   ┌──────────────────────────────────────────────────────────────┐   │  │
│  │   │  MySQL 直方图统计 (基础) ────────────────────────────────────│   │  │
│  │   │       ↑                                                       │   │  │
│  │   │       │ AI 校正                                               │   │  │
│  │   │       │ final_estimate = α * mysql_estimate + (1-α) * ai_est  │   │  │
│  │   │       │ α 根据历史准确率动态调整                              │   │  │
│  │   │  ┌────┴─────┐                                                │   │  │
│  │   │  │ AI Model │ (可禁用)                                       │   │  │
│  │   │  └──────────┘                                                │   │  │
│  │   └──────────────────────────────────────────────────────────────┘   │  │
│  │                                                                       │  │
│  └──────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
│  // 混合决策代码                                                            │
│  double estimate_cardinality_hybrid(const Query& q) {                       │
│      // 传统估计 (永远执行)                                                 │
│      double mysql_est = mysql_traditional_estimate(q);                      │
│                                                                             │
│      // 检查 AI 是否可用                                                    │
│      if (!srv_ai_cardinality_enabled || ai_model_ == nullptr) {             │
│          return mysql_est;                                                  │
│      }                                                                      │
│                                                                             │
│      // AI 估计                                                             │
│      double ai_est = ai_model_->predict_cardinality(q);                     │
│                                                                             │
│      // 动态权重 (基于历史准确率)                                           │
│      double alpha = ai_stats_.get_confidence();  // 0.0 ~ 1.0              │
│                                                                             │
│      // 加权组合                                                            │
│      double final_est = alpha * ai_est + (1 - alpha) * mysql_est;           │
│                                                                             │
│      // 合理性检查                                                          │
│      if (final_est < 1 || final_est > max_possible(q)) {                    │
│          ai_stats_.record_anomaly();                                        │
│          return mysql_est;  // AI 估计异常，回退                            │
│      }                                                                      │
│                                                                             │
│      return final_est;                                                      │
│  }                                                                          │
│                                                                             │
│  【置信度自适应】                                                            │
│                                                                             │
│  AI 置信度 α 的更新规则:                                                    │
│  ┌──────────────────────────────────────────────────────────────────────┐  │
│  │                                                                       │  │
│  │  初始: α = 0.5  (AI 和传统各占一半)                                  │  │
│  │                                                                       │  │
│  │  每次执行后:                                                          │  │
│  │    ai_error = |ai_est - actual| / actual                              │  │
│  │    mysql_error = |mysql_est - actual| / actual                        │  │
│  │                                                                       │  │
│  │    if ai_error < mysql_error:                                         │  │
│  │        α = min(0.9, α + 0.01)   // AI 更准，增加权重                  │  │
│  │    else:                                                              │  │
│  │        α = max(0.1, α - 0.01)   // MySQL 更准，降低 AI 权重          │  │
│  │                                                                       │  │
│  │  经过足够多样本，α 会收敛到反映真实准确率的值                         │  │
│  │                                                                       │  │
│  └──────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

```
│  │ 在线微调         │ - 持续优化              │ - 需要训练基础设施      │  │
│  │                  │ - 适应任意场景          │ - 冷启动期效果一般      │  │
│  │                  │ - 模型体积小            │ - 微调可能导致遗忘      │  │

│  │                                                                       │  │
│  │   1. 初始部署: 使用 "AI + 规则混合" 方案                             │  │
│  │      - 风险最低，保证稳定性                                          │  │
│  │      - AI 置信度从低开始，逐渐建立信任                               │  │
│  │                                                                       │  │
│  │   2. 有足够数据后: 添加 "在线微调"                                   │  │

│  │   3. 成熟阶段: 可选 "多模型选择器"                                   │  │
│  │      - 识别出明显不同的负载模式                                      │  │
│  │      - 为每种模式训练专门模型                                        │  │
```
